Project Workflow

Animated flow for secure onboarding and MFA setup.

1

Register user

Create a new account with username, password, and optional email address.

2

Login with JWT

Obtain a bearer token from `/auth/token` for authenticated access.

3

Setup MFA

Call `/mfa/setup` to generate a secret and scan the QR code in your Authenticator app.

4

Verify code

Send the TOTP token with username and access token to `/mfa/verify`.

Core Endpoints

All of these routes are ready in Swagger once the app is running.

POST /auth/register

Register a new user account and store hashed credentials safely.

{ "username": "user", "password": "pass", "email": "optional" }

POST /auth/token

Authenticate with username/password and receive a JWT access token.

form data: username, password, [mfa_token]

POST /mfa/setup

Generate a TOTP secret and QR code for Authenticator app setup.

POST /mfa/code

Generate a verification code from shared secret and authenticated user state.

POST /mfa/verify

Validate the Authenticator token and enable MFA for the user.

{ "username": "user", "access_token": "bearer", "token": "123456" }
